# USE CASE: 7 All Cities in the World

## CHARACTERISTIC INFORMATION

### Goal in Context

As a *user* I want *to produce a report of all cities in the world organised by largest population to smallest* so that *the organisation can access population information.*

### Scope

Organisation.

### Level

Primary task.

### Preconditions

Database contains city and country population data.

### Success End Condition

A cities report is available to the organisation.

### Failed End Condition

No report is produced.

### Primary Actor

User.

### Trigger

The user requests all cities in the world.

## MAIN SUCCESS SCENARIO

1. User requests all cities in the world.
2. User extracts all cities, ordered by population, largest to smallest.
3. User produces the report with columns: name, country, district, and population.
4. User provides the report to the organisation.

## EXTENSIONS

None.

## SUB-VARIATIONS

None.
